# Qatar area search data

`qatar-areas.json` is a small offline derivative of the [GeoNames Qatar country extract](https://download.geonames.org/export/dump/QA.zip), downloaded 2026-10-11. GeoNames provides reusable geographic data under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), including commercial use. Attribution appears in the picker. Map data is separately attributed to OpenStreetMap/OpenMapTiles/OpenFreeMap by the map control.

The conversion retains 268 Qatar populated-place/neighborhood and current municipality points (`PPL`, `PPLA`, `PPLA2`, `PPLC`, `PPLX`, `ADM1`). Abandoned/historical places, hotels, wells, mosques and other POIs are excluded. Each result retains its original GeoNames ID, coordinates, source update date and alternate names. 266 have a name in Arabic script; two have no Arabic name in the extract. Coordinates are checked against the downloaded records, not surveyed building entrances. The source does not guarantee completeness, freshness or accuracy.

Changes from the source: filtering, renaming columns, choosing a display name, extracting Arabic-script names and deduplicating aliases. The original extract and readme are in `geonames-source/`; the source SHA-256 is recorded in the derived JSON. No coordinates are invented. Search normalizes accents, Arabic diacritics, articles and common vowel variants; it never automatically chooses a result. Municipality and area search is not building geocoding or delivery coverage verification. The dataset is not exhaustive; notably some familiar marketing names, such as West Bay and The Pearl, are absent as area records. Use the map/manual address when a name is absent.

To update, deliberately download the current `QA.zip`, extract `QA.txt` to `data/geonames-source/`, review changed records and run `node scripts/build-qatar-areas.cjs`. Update the retrieval date in the script. The source IDs can be inspected at `https://www.geonames.org/<id>/`. Do not add hotel coordinates as neighborhood centers. A one-time Overpass attempt was unavailable; there is no Overpass or GeoNames web-service dependency in checkout.
